# Release Notes — v2.3.0

**Date:** 2026-03-21  
**Type:** Complete CoC Analytics Modernization (CoC-1 to CoC-5)

---

## Summary

Comprehensive overhaul of the Cost-of-Carry (CoC) module. This release shifts from relying on cumulative daily data to true instantaneous order book depth, scales thresholds based on annualized percentages, adds fair-value dividend adjustment, and contains three critical bug fixes for the charting series.

---

## What's New & Changed

### 1. `CoC-3`: L1 Depth for OBI (`get_atm_obi` & `get_futures_obi`)
- Replaced cumulative `bid_qty`/`ask_qty` totals with the instantaneous Level-1 order book depth (`bid1_qty`/`ask1_qty`).
- Added robust `COALESCE(col, 0)` guards to prevent NULL-propagation from illiquid strikes/contracts.

### 2. `CoC-1`: Annualized Percentage Thresholds
- `config.py` now defines thresholds in **annualized percentages** (`VCOC_BULL_THRESHOLD_PCT`, `COC_DISCOUNT_THRESHOLD_PCT`, etc.) to unify behavior across different underlyings.
- Both `get_coc_latest()` and `get_coc_series()` now accurately extract `DTE` (Days to Expiry) and return `coc_pct` and `vcoc_pct` directly in the payload.
- `_coc_signal()` utilizes the percentage thresholds (falling back to absolute thresholds if DTE is unavailable).

### 3. `CoC-2`: Fair-Value Dividend Adjustment
- Added new underlying `DIVIDEND_YIELD` parameters and a global `RISK_FREE_RATE` in `config.py` (with startup validation).
- Implemented `_fair_value_coc()` to compute theoretical fair value.
- The `DISCOUNT` signal now fires based on `coc_fv_premium` (deviation from theoretical value) rather than raw CoC, effectively preventing false bearish signals on ex-dividend days.

### 4. `CoC-5`: Documentation Corrigenda
- Fixed ambiguous operator precedence in the OBI formula within the `Docs/technical_reference.md` file.

### 5. Critical Bug Fixes
Fixed three newly discovered bugs in the original branch:
- **Bug-1 (Critical):** `get_coc_series()` was crashing on every call due to a missing `result = []` initialization.
- **Bug-2 (High):** `get_coc_series()` was missing `fut_price` in the SQL `SELECT` causing `_coc_signal` to silently skip applying the fair-value dividend adjustment to the chart series.
- **Bug-3 (Medium):** The `DISCOUNT` gate was evaluating absolute Rupee points against an annualized percentage threshold. This unit mismatch has been resolved by converting `coc_fv_premium` to an annualized percentage prior to evaluation.
