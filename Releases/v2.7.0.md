# OptDash v2.7.0 — Part B Analytics Upgrades

## Overview
This release finalizes Phase B of the IV and VEX/CEX Analytics engine overhaul, fulfilling the remaining backlog of parameterizations, signal API modifications, and edge-case analytical fixes.

## 1. Parameterization of AI & Analytics
Several hardcoded thresholds deep within the mathematical models were cleanly transposed into safe, typed constants within `optdash/config.py` to allow runtime `.env` overrides:
- **PCR Engine:** Extracted `PCR_Z_PANIC_THRESHOLD` (1.5), `PCR_Z_BUILDING_THRESHOLD` (0.8), and `PCR_Z_FADING_TREND`, enabling operators to loosen or tighten contrarian retail-panic signals effortlessly.
- **Confidence Matrix Cold Start:** Paramerized Bucket 4 thresholds via `CONFIDENCE_B4_MIN_TRADES` (5 trades) and `CONFIDENCE_B4_SCALE` (12), securing the model against low-sample-size trade-win extrapolations.
- **Alert Controls:** Integrated configurable scalars `SKEW_ELEVATED_THRESHOLD` (5.0%) and `ZGL_PROXIMITY_PCT` (0.5%).

## 2. Advanced Data Routes & API Tooling
- **Per-Strike VEX/CEX Exposures:** Elevated internal dict calculations down to a dedicated REST endpoint `GET /vex-cex/by-strike` inside the Micro router. This provides instantaneous strike-by-strike Dealer positioning data intended explicitly for frontend Heatmaps.
- **Strike Screener Direction Hooks:** Added the `direction_aligned` metadata flag directly into the response JSON output of the Screener's `S_Score` ranking pipeline, avoiding frontend computational bloat.
- **Recommender Routing:** Wired `iv_data` natively through the unified scoring protocol bridging the structural Volatility Risk Premium (VRP/IVP) signals directly into the `compute_confidence()` engine logic.

## 3. Sophisticated Composite Alert Generation
- **Skew × VEX Convergence:** Deployed a highly calibrated `HIGH_CONVICTION_BEAR` alert trigger to monitor options market volatility. It activates only when Put-skew explicitly flips to a **STEEPENING** state *concurrently* alongside severely net-short Dealer Vanna (`VEX`).
- **Zero Gamma Level Proximity:** Injected two complementary transition alerts (`APPROACHING_ZGL` and `BELOW_ZGL`) which constantly track and contextualize the current SPOT asset price in direct mathematical percentage proximity to the market's consolidated Zero Gamma Level.
