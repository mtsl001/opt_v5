# Release v2.8.1 — Screener Threshold Recalibration & Pipeline Tracking

This patch release recalibrates the S_score star rating thresholds following the structural enhancements made in `v2.8.0`, and officially registers a pending pipeline dependency for the new momentum factor.

## ⚙️ Star Threshold Recalibration
- **Context:** The addition of the momentum signal ($+30$ pts) and delta normalization expanded the theoretical maximum `S_score` from $150$ to $180$. The existing star thresholds were too low for this new scale.
- **Update:** Config thresholds have been re-anchored to preserve the model's selectivity criteria:
  - `STAR_4` $\ge$ `120.0` (previously 100) — top tier execution.
  - `STAR_3` $\ge$ `95.0` (previously 80).
  - `STAR_2` $\ge$ `70.0` (previously 60).

## 📋 Pipeline & Processor Tracking
- **Momentum Factor Dependency:** Logged a pending task in `Upgrade_plan.txt`. The new momentum calculation (`volume / avg_volume_20d`) requires `avg_volume_20d` to be dynamically exposed in `options_data`. Until this column is actively resolved in the data processor pipeline, the momentum score safely fails over to `0` instead of crashing the analytical query.
