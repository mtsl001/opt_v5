# Release v2.9.1 — Environment Gate Hardening

This patch release addresses three residual logic items identified during the `v2.9.0` verification review.

## 🛡️ Logic & Gating Adjustments
- **Momentum Double-Counting Prevention (Issue #3):** The V_CoC (`vcoc_signal`) and Futures OBI (`fut_bs_ratio`) checks have been explicitly combined into a single 2-point composite gate condition (`vcoc_fut_combined`). Because both metrics measure the same institutional flow event, combining them ensures they only fire together and stops a single event from double-counting and inflating the momentum score.
- **Safe Volume Guard Defaults (Issue #4):** Hardened the volume guard logic to safely fail open (`volume_ok = True`) if the required `avg_snap_volume_20d` data point is missing from the underlying data pipeline, preventing the gate from rejecting valid setups against a dangerous fallback default.

## ⚙️ Documentation Updates
- Corrected the stale comment under `DEALER_OCLOCK_START` in `config.py` to accurately document the DTE=1 regime switch where the C10 penalty is inverted into a bonus, clarifying the gate's alignment with charm-hedging flow.
