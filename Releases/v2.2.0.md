# Release Notes — v2.2.0

**Date:** 2026-03-21  
**Type:** GEX Analytics Upgrade

---

## Summary

Five upgrades to the GEX analytics module. Improved signal accuracy, eliminated redundant DuckDB scans at 1-min cadence, and added two new signals: Zero Gamma Level and GEX Momentum.

**One feedback item rejected:** GEX-1 (dynamic CE/PE direction) — the CE=+1/PE=−1 convention is mathematically correct for dealer hedging mechanics and applies equally to NSE.

---

## Changes

### `gex.py`

| Change | Description |
|---|---|
| **GEX-4 Persistent peak cache** | Module-level `_PEAK_CACHE` dict survives across ticks. At 1-min cadence: peak lookup **24 ms → 0.003 ms** (8,000× faster). `reset_peak_cache()` added for EOD rollover. |
| **GEX-5 Unified series peak** | `get_gex_series()` now uses `_get_gex_peak()` (DuckDB, cached) instead of in-memory `max()`. Chart and live tile now share identical `pct_of_peak` denominators. |
| **GEX-3 `regime_near`** | `get_net_gex()` adds `regime_near` + `pct_near_of_peak` driven by TIER1+TIER2 GEX only. Prevents TIER3 (monthly/quarterly) OI from masking intraday regime shifts. |
| **GEX-2 Zero Gamma Level** | `get_net_gex()` adds `zgl` (₹ strike), `spot_vs_zgl` (% distance), `above_zgl` (bool). ZGL is the interpolated strike where cumulative per-strike GEX crosses zero — the primary structural S/R level from GEX. |
| **GEX-6 GEX Momentum** | `get_net_gex()` adds `gex_momentum_B` and `momentum_direction` (`BUILDING` / `FADING` / `FLAT`). Compares current vs 5-snap trailing avg (= 5 min at 1-min cadence). |

### `config.py`
- `GEX_MOMENTUM_SNAPS: int = 5` added

### `environment.py`
- Gate C1 (`gex_declining`) now uses `pct_near_of_peak` as primary. Falls back to `pct_of_peak` when unavailable.

### `scheduler.py`
- EOD sweep calls `reset_peak_cache(trade_date)` to clear stale entries before next-day first tick.
