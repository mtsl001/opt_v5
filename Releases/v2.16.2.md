# OptDash v2.16.2 - System Integrity Audit (Pass 5)

## Overview
This release addresses the final 11 bugs identified during the extensive Pass-5 system integrity audit. The focus here is on robust SQL protection, eliminating division-by-zero crashes, and reducing excessive full-day database aggregations down to efficient trailing windows.

## Security & Reliability
- **SQL Injection Safeguard (`screener.py`):** Added explicit python `direction in ('CE', 'PE')` boundary gating to prevent untrusted string interpolation against the dynamic execution `direction_clause`.
- **Zero-Division Bounds (`screener.py`, `coc.py`):** Wrapped normalized denominators with `NULLIF(? - ?, 0)` inside the `Delta` sensitivity query. Enforced `max(dte, 1)` bounds for velocity cost of carry percentages.
- **API Resilience (`screener.py`):** Suppressed the blind `raise` inside `get_strikes()` falling back to local empty arrays. This prevents unhandled `HTTP 500` stack traces from cascading up to the visualization layers.

## API Performance (N+1 Query Elimination)
- **Bounded Table Queries (`alerts.py`):** Drastically cut DuckDB traversal by injecting decoupled `since_snap` parameters directly into the downstream analytical pipelines (`gex, pcr, coc, microstructure`). Queries now restrict array sweeps strictly against active trailing bounds rather than repeated 09:15-to-present complete day fetches.
- **Redundant Trigger Breaks (`vex_cex.py`):** Blocked isolated inner `net_gex` loops by passing surrounding live scopes down onto the state variables implicitly.

## Configuration & Logic Fixes
- **Static Defactoring (`pnl.py`):** Decoupled statically baked `15:30` evaluation thresholds, enforcing mathematical bounds dynamically against external `.env` states via `SESSION_CLOSING_START`.
- **Session Validation Context (`confidence.py`):** Restructured state equations explicitly checking isolated `raw != raw_pre_session` constraint derivations. The string-reason flags will no longer persist independently during capped override sessions.
- **Rolling Central Trajectories (`microstructure.py`):** Rebuilt true indexing scopes isolating pure center mathematics securely against shifting odd and even boundary truncations naturally.
- **Duplication Spread (`alerts.py`):** Overlaid deduplication hashes squarely onto the underlying enum class labels, shielding output limits securely against duplicate trailing logs crossing adjacent snapshot limits.
