# OptDash v2.12.0 (Confidence Metrics & Quality Normalisation Release)

This release ships the third and final batch of foundational system reliability fixes, specifically targeting algorithmic precision, scaling limits, and historical fallback protections across the `confidence` and `quality` engines.

## Confidence Engine Upgrades (`confidence.py`, `config.py`)
- **B4 Scale Overflow Repair (Issue #2)**: Realigned the algorithmic `CONFIDENCE_B4_SCALE` multiplier back to a clean `10`. This eliminates latent integer overflow bugs masked beneath the `min()` cap during high-win-rate periods.
- **Cold-Start Proportional Rescaling (Issue #3)**: Activated intelligent `100/90` rescaling logic across B1/B2/B3 scores during system cold-starts (or `is_fallback` modes). This rescues otherwise perfect intraday and `DTE=0` trades from silent execution blocks just because the platform lacks legacy trades. Injects a tracked `cold_start: bool` flag into the recommendation schema.
- **Statistical Significance Thresholds (Issue #4)**: Escalated the `CONFIDENCE_B4_MIN_TRADES` threshold from 5 back to 15, aggressively shielding live automated setups from false confidence balloons derived from micro win-streaks.
- **Smart Midday Penalties (Issue #8)**: Rewrote the `MIDDAY_CHOP` restriction sequence, implementing a gated `SESSION_MIDDAY_SMART_PENALTY=True` routine. Exceptionally strong structural trades (`b1 >= 35`) that are fully confirmed by contrarian internals (`pcr_mod > 1.0`) are now granted a relaxed `-5` penalty instead of the standard `-10` suppression.

## Quality Engine Overhauls (`quality.py`)
- **C2 Gate Component Scaling (Issue #5)**: Overhauled the algorithmic calculation of the `C2` environment bucket internally. Shifted the gating formula's division target from the abstract `GATE_MAX_SCORE` to the precise `GATE_GO_THRESHOLD` so structurally healthy trading environments explicitly capture and contribute maximal permitted Quality scaling weight.
- **Normalisation Symmetry (Issue #6 & #7)**: Updatd all inline configuration constants to accurately flag `_SSCORE_NORM` as roughly `≈ 128` matching live configuration weighting output. Fastened dependency flags to `compute_quality_score()` definitively confirming structural cross-pollution mechanisms affecting the C2 array structure for downstream architectures.
